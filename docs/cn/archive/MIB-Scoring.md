# 0. 规范目标

本规范定义了 MIB 如何将基准评测观测数据逐级计算并转换为：

```text
探针得分（Probe scores）
场景实例得分（Scenario scores）
场景模板得分（Template scores）
能力维度得分（Dimension scores）
因果记忆度量指标（Causal memory metrics）
MIB 综合得分（MIB Score）
能力卡片报告（Capability Cards）
排行榜统计分析（Leaderboard statistics）
```

计分体系围绕一个核心立论构建：

> **MIB 综合得分（MIB Score）衡量受评智能体在记忆赋能下的绝对任务能力；因果度量指标则独立衡量该能力究竟有多大比例是由记忆所因果诱发的。**

这是紧密关联但本质不同的两个问题。

一个推理能力极强的智能体，即使在关键记忆被消融后，依然可能凭借自身强大的基座模型取得不错的绝对分数。

反之，一个基础能力较弱的智能体，虽然记忆系统为它带来了显著的增益，但在最终绝对任务表现上可能依然偏低。

因此，MIB 必须同时且独立地报告两类数据：

```text
记忆赋能下的绝对任务能力
+
记忆对认知决策的因果贡献
```

二者严禁相互混淆或隐式折算。

# 1. 计分设计哲学

MIB 坚决避免将记忆能力评测简化为单一的：

```text
检索准确率（retrieval accuracy / Recall@K）
```

或是粗暴的：

```text
有记忆得分 - 无记忆得分
```

评测基准必须能够清晰回答一系列相互独立的认知问题：

```text
智能体能否完成未来的目标任务？
相关的关键记忆是否起到了正向帮助？
无关的背景噪音记忆是否保持了良性中立？
陈旧或有害的误导性记忆是否引发了原本可避免的错误？
过往的失败教训是否有效降低了重复犯错率？
习得的技能是否做到了仅在适用情境下进行迁移？
这些表现跨运行实例与隐藏实例化数据时的统计稳定性如何？
```

MIB 计分模型完整维系并呈现了上述所有关键区分。

# 2. 绝对能力 vs 因果贡献

MIB 提供两个核心计分输出面：

## 2.1 综合能力面（Capability Surface）

**MIB Score** 及其所属的能力维度用于衡量：

> 受评测的记忆赋能智能体，在需要记忆智能支持的复杂任务上，综合表现究竟处于何种水平？

全量记忆条件（Full Memory）下的实际表现是计算能力得分的核心输入。

## 2.2 因果贡献面（Causal Surface）

一系列专属因果指标：

```text
因果记忆效应（Causal Memory Impact, CMI）
记忆收益（Memory Benefit, MB）
记忆损害（Memory Harm, MH）
净记忆增益（Net Memory Gain, NMG）
无关记忆稳定性（Irrelevant Memory Stability, IMS）
负迁移率（Negative Transfer, NT）
已知错误重现率（Error Recurrence, ERR）
```

用于衡量：

> 当通过实验手段对记忆条件施加配对干预时，智能体的行为发生了何种量化改变？

“因果记忆效应”能力维度将部分关键干预转化为 0~100 的标准化能力子项，但原始的因果度量指标依然保持独立列报。

# 3. 为何 MIB 主分不能是单纯的差值（Delta）

假设存在两个系统：

```text
系统 A：
  全量记忆得分（Full Memory）      = 95
  消融关键记忆得分（Relevant Ablated） = 85

系统 B：
  全量记忆得分（Full Memory）      = 65
  消融关键记忆得分（Relevant Ablated） = 20
```

若单纯以差值（$\Delta$）论高低：

```text
系统 A 增益 = +10
系统 B 增益 = +45
```

单纯看差值会得出“系统 B 明显优于系统 A”的结论，但事实上系统 A 在解决未来任务的实际能力上远胜系统 B。

反之，若只看全量得分 95 vs 65，又会掩盖系统 A 对记忆系统的依赖度其实低于系统 B 的客观事实。

因此，MIB 的标准输出方式为：

```text
绝对能力水平：
  系统 A > 系统 B

因果记忆收益：
  系统 B > 系统 A
```

两者相互补充，提供完整且真实的认知画像。

# 4. 赛道计分语义约定

## 4.1 赛道 A —— 记忆系统赛道（Track A）

基准严格固定基座模型、智能体 Prompt、工具集与任务环境，唯一变量是记忆系统。

因此，MIB Score 的差异可以直接且纯粹地归因于记忆系统本身的优劣。赛道 A 是横向对比不同记忆架构的首选公共榜单。

## 4.2 赛道 B —— 完整智能体赛道（Track B）

参赛方可全面定制模型、策略与记忆系统，MIB Score 衡量软硬件一体化智能体的端到端综合水平。

该分数**刻意不对基座大模型进行任何形式的数学归一化**；因果指标则用于透视该完整系统内部的记忆利用效率。

## 4.3 严禁跨赛道混排

赛道 A 与赛道 B 严禁合并到同一个榜单中直接排名。

# 5. 计分层级结构

标准计算链路：

```text
评测器结果（Evaluator Result）
      ↓
探针得分（Probe Score）
      ↓
场景实例得分（Scenario Instance Score）
      ↓
场景模板得分（Scenario Template Score）
      ↓
能力维度得分（Dimension Score）
      ↓
MIB 综合得分（MIB Score）
```

配对消融实验形成独立的因果计算分支：

```text
全量记忆条件（Full Condition）
      │
      ├── 相关记忆消融（Relevant Ablation）
      ├── 无关记忆消融（Irrelevant Ablation）
      ├── 无记忆对照（No-Memory Control）
      └── 有害/陈旧记忆条件（Harmful/Stale Condition）
              ↓
       因果度量指标（Causal Metrics）
              ↓
  因果记忆效应维度（Causal Memory Impact Dimension）
```

# 6. 基础数值定义域

内部计算统一采用归一化表现值：

\[
p \in [0,1]
\]

最终呈现的能力分值映射至 0~100 区间：

\[
score = 100p
\]

示例：

```text
0.00  →   0.0
0.73  →  73.0
1.00  → 100.0
```

因果差值指标（Delta）可以为负数，通常以**百分点（percentage points, pp）**呈现：

```text
+0.284 → +28.4 pp
-0.071 →  -7.1 pp
```

---

# 7. 严禁过早取整

所有中间层级的聚合计算必须保持完整的双精度浮点精度，四舍五入仅在最终呈现报告时进行。

推荐展示精度：

```text
MIB 综合得分 (MIB Score)             82.7
维度得分 (Dimension Score)            84.3
记忆收益 (Memory Benefit)            +21.8 pp
记忆损害 (Memory Harm)                4.2 pp
错误重现率 (Error Recurrence Rate)     7.5%
```

---

# 8. 评测器判定输出

每个评测器产出标准化的结构对象：

```json
{
  "score": 0.85,
  "passed": true,
  "failure_codes": [],
  "details": {}
}
```

必须保证 `score ∈ [0,1]`。

---

# 9. 精确匹配评测器（Exact Evaluator）

用于确定性的标量/字符串判定：

\[
e =
\begin{cases}
1 & \text{完全正确}\\
0 & \text{错误}
\end{cases}
\]

---

# 10. 集合匹配评测器（Set-Match Evaluator）

对智能体输出进行标准归一化（如忽略大小写、去除首尾空格）后与接受答案集匹配，命中任一合法答案即判定为 1，否则为 0。

---

# 11. 结构化评测器（Structured Evaluator）

对多字段 JSON 进行分别校验与加权计算：

\[
e = \sum_k w_k e_k,\quad \sum_k w_k = 1
\]

---

# 12. 世界状态评测器（World-State Evaluator）

直接对世界模拟器的环境断言求值。若包含多条断言：

\[
e = \frac{\text{满足的断言数}}{\text{总断言数}}
\]

客观世界环境断言的判定效力永远高于自然语言回答。

---

# 13. 动作轨迹评测器（Trajectory Evaluator）

仅基于可观测的外部工具调用流水与动作序列打分，绝不依赖私有思维链。

---

# 14. 语义约束评测器（Semantic-Constraint Evaluator）

对自然语言回答中必须包含（`must_include`）或严禁包含（`must_not_include`）的关键语义进行结构化校验，结果严格归一化至 `[0,1]`。

---

# 15. 大模型裁判评测器（LLM Judge Evaluator）

必须制定明确的评分细则（Rubric）与阶梯映射定义（如 0, 0.25, 0.5, 0.75, 1.0），严禁使用模糊主观偏好。

---

# 16. 单探针多评测器约定

标准场景包中，每个探针通常关联**单个最终评测器**。若需融合多项指标，应在场景中显式定义**复合评测器（Composite Evaluator）**并指定各子项权重。

---

# 17. 复合评测器计算公式

\[
E_q = \sum_j \alpha_j e_j,\quad \alpha_j \ge 0,\quad \sum_j \alpha_j = 1
\]

---

# 18. 探针得分形式化定义

针对探针 $q$、评测条件 $c$、第 $r$ 次重复运行：

\[
P_{q,c,r} \in [0,1]
\]

标准条件标识：

```text
full    全量记忆条件
rel     相关记忆消融条件
irr     无关记忆消融条件
none    完全无记忆对照条件
harm    有害诱导记忆条件
stale   陈旧过时记忆条件
counter 注入反例测试条件
```

---

# 19. 探针内部权重

场景内各探针权重 $w_q \ge 0$（默认 1.0），代表其在**单场景内部**的相对重要性。

---

# 20. 随机性与重复运行平均

针对非确定性系统，在特定条件 $c$ 下执行 $R$ 次重复运行：

\[
\bar{P}_{q,c} = \frac{1}{R} \sum_{r=1}^{R} P_{q,c,r}
\]

---

# 21. 因果条件配对执行铁律

全量运行与各消融变体必须严格按运行种子（seed）进行一一配对：

```text
全量运行 第 1 轮
相关记忆消融 第 1 轮
无关记忆消融 第 1 轮
有害记忆测试 第 1 轮
```

各条件共享完全相同的场景实例参数、世界初始种子、未来探针与工具模拟器配置，唯一变量只能是设定的记忆干预。

---

# 22. 为什么严禁非配对抽样

严禁拿“100 次随机全量运行的均值”去减“另外 100 次无关消融运行的均值”。严格配对的差值能够大幅抵消基座模型自身波动与题目难度的随机干扰，是因果推断有效性的基石。

---

# 23. 场景全量条件得分

针对场景实例 $s$、第 $r$ 次运行的全量条件：

\[
S_{s,r}^{full} = \frac{\sum_q w_q P_{q,full,r}}{\sum_q w_q}
\]

---

# 24. 场景实例平均表现

\[
F_s = \frac{1}{R} \sum_r S_{s,r}^{full}
\]

$F_s \in [0,1]$ 即为该场景实例在全量记忆下的绝对表现。

---

# 25. 非加权聚合器

若场景显式指定了 `min` / `max` 等聚合器，Runner 按其规则求值。`min` 常用在要求所有安全/正确性子项均不得犯错的高危场景。

---

# 26. 场景级扣分惩罚

针对严重病态的扣分（$g_k$）在探针得分聚合后执行：

\[
F'_s = \max(0, F_s - \sum_k g_k)
\]

---

# 27. 场景惩罚上限

场景可设置惩罚上限（Penalty Cap），防止多项重叠的检测器导致无限度重复扣分。

---

# 28. 场景惩罚 vs 全局安全防线

场景惩罚只作用于单个场景得分；全局安全防线惩罚作用于最终榜单卡片，且必须显式公开、版本化并单独列报。

---

# 29. 场景对多能力维度的贡献分配

场景可将其表现按权重分配给多个能力维度（权重之和为 1）：

```json
{
  "dimension_weights": {
    "temporal_memory": 0.70,
    "retention_retrieval": 0.15,
    "causal_memory_impact": 0.15
  }
}
```

---

# 30. 场景内部维度权重的内涵

代表该场景为各个能力维度提供的评测信息量占比。缺省时默认均分。

---

# 31. 探针级维度过滤

若探针显式声明了所属维度 $d$，则在计算该场景对维度 $d$ 的贡献时，仅提取关联探针 $Q_d$ 的表现：

\[
S_{s,d} = \frac{\sum_{q \in Q_d} w_q \bar{P}_{q,full}}{\sum_{q \in Q_d} w_q}
\]

---

# 32. 因果维度的特殊计算规则

对于 `causal_memory_impact` 维度，其得分必须严格由配对消融干预指标计算得出，绝不能直接复用全量得分 $F_s$。

---

# 33. 场景实例与场景模板的分层聚合

一个场景模板（Template）可通过随机参数生成数百个隐藏实例（Instances）。

MIB **严禁**直接将所有实例混合平铺计算，否则廉价易生成的模板会凭借实例数量绑架整个维度的得分。

标准计算分两步走：

```text
模板内部所有实例求均值 → 得出模板得分（Template Score）
各模板得分加权求和 → 得出维度得分（Dimension Score）
```

---

# 34. 场景模板得分公式

针对模板 $t$、维度 $d$、包含 $N_t$ 个具象化隐藏实例：

\[
T_{t,d} = \frac{1}{N_t} \sum_{s \in t} S_{s,d}
\]

---

# 35. 模板分层聚合的核心价值

确保基准的核心权重完全由**场景体系的结构设计**所决定，绝不随某个模板生成的实例数量多少而发生漂移。

---

# 36. 模板在维度内的权重

评测包为模板 $t$ 分配在维度 $d$ 内的权重 $v_{t,d} \ge 0$（默认均等）。

---

# 37. 能力维度得分公式

针对能力维度 $d$：

\[
D_d = 100 \cdot \frac{\sum_t v_{t,d} T_{t,d}}{\sum_t v_{t,d}},\quad D_d \in [0,100]
\]

这就是能力卡片上展示的各维度标准得分。

---

# 38. 八大核心能力维度与标准权重

| 能力维度 | 推荐权重 $W_d$ |
| :--- | :---:|
| 保留与检索（Retention & Retrieval） | 0.12 |
| 时序记忆（Temporal Memory） | 0.13 |
| 认识状态记忆（Epistemic Memory） | 0.15 |
| 经验记忆（Experience Memory） | 0.15 |
| 技能学习与迁移（Skill Learning & Transfer） | 0.15 |
| 选择性遗忘（Selective Forgetting） | 0.10 |
| 前瞻与自我认知记忆（Prospective & Self Memory） | 0.08 |
| 因果记忆效应（Causal Memory Impact） | 0.12 |
| **总计** | **1.00** |

---

# 39. MIB 基准得分（Base Score）

\[
MIB_{base} = \sum_d W_d D_d \in [0,100]
\]

---

# 40. 默认 MIB 综合得分

在无全局安全防线额外扣分的前提下：

\[
MIB = MIB_{base}
\]

---

# 41. 全局安全防线惩罚（Guardrail Penalty）

若触发全局违规惩罚 $G_{global} \ge 0$：

\[
MIB = \max(0, MIB_{base} - G_{global})
\]

能力卡片上必须完整展示基准分、扣除项与最终分。

---

# 42. 测试覆盖率度量（Coverage）

\[
Coverage_d = \frac{\text{已执行的必测模板权重}}{\text{该维度要求的必测模板总权重}} \in [0,100\%]
\]

---

# 43. 不支持场景的判定

若系统因缺少特定接口导致必测场景无法执行，该提交将被判定为**当前 Profile 下不满足准入资格（ineligible）**，绝不能静默剔除题目以虚高分数。

---

# 44. 部分覆盖得分（Partial Score）

对于未达到 100% 覆盖率的学术探索提交，必须显式标注为 `Partial MIB Score`，严禁与官方全量榜单直接混列。

---

# 45. Profile 命名与得分绑定

任何得分必须严格绑定其 Profile 名称（如 `MIB-Core-0.1`、`MIB-Full-1.0`），严禁跨 Profile 混淆。

---

# 46. 基础设施执行失败处理

重试后依然无法恢复的基础设施异常，在官方榜单中探针判定为 0 分，并记录 `execution_failure = true`，防止系统通过主动崩溃来逃避难题。

---

# 47. 认知失败 vs 基础设施失败

两者在报告产物中必须有清晰的分类标记，为工程排障提供透明线索。

---

# 48. 配对因果实验符号系统

在配对场景实例中，各条件的归一化得分记作：

```text
F: 全量记忆条件得分（Full Memory）
R: 相关关键记忆消融得分（Relevant Ablated）
I: 无关噪音记忆消融得分（Irrelevant Ablated）
N: 完全无记忆对照得分（No Memory）
H: 有害/诱导记忆条件得分（Harmful Memory）
C: 纯净对照条件得分（Clean Control）
```

---

# 49. 因果对照参考基准的优先级

衡量关键记忆贡献时，优先采用**相关记忆精准消融（R）**；在缺乏精准消融时，采用**无记忆对照（N）**。

---

# 50. 原始因果记忆效应（Raw CMI）

在单组配对实验中：

\[
CMI_{raw} = F - R \in [-1, 1]
\]

正值代表记忆带来了实际帮助；负值代表记忆反而导致了性能下降。报告中必须保留真实符号，严禁截断。

---

# 51. 记忆收益（Memory Benefit, MB）

在所有配对样本上的平均增益：

\[
MB = E[F - R]
\]

以百分点（pp）列报，如 $MB = +28.4\text{ pp}$。

---

# 52. 为什么原始 MB 不能直接作为因果维度得分

$R=0 \rightarrow F=0.2$ 与 $R=0.7 \rightarrow F=0.9$ 的原始增益都是 $+0.2$，但后者几乎填满了全部可提升的认知空间。因此因果维度需要引入空间归一化指标。

---

# 53. 净空间归一化记忆收益（HMB）

针对具备可提升空间（$R < 1 - \epsilon$）的配对样本：

\[
HMB = \frac{\max(0, F - R)}{1 - R} \in [0, 1]
\]

衡量记忆系统填补了消融后剩余可提升空间的百分比。

---

# 54. 接近天花板样本的排除规则

若消融后得分已处于天花板（$R \ge 1 - \epsilon$，默认 $\epsilon=0.02$），说明该任务本就无需记忆即可满分，此类样本不纳入 HMB 的计算。

---

# 55. 负向因果效应的处理

若 $F < R$，则正向增益 $HMB = 0$，但该负向差值完整保留在原始 CMI 与记忆损害（Memory Harm）的统计中。

---

# 56. 基于无记忆对照的收益指标

在采用无记忆对照时：

\[
MB_{none} = F - N,\quad HMB_{none} = \frac{\max(0, F - N)}{1 - N}
\]

---

# 57. 无关记忆稳定性（IMS）

衡量剔除无关背景噪音后表现的稳定程度：

\[
IMS = 1 - |F - I| \in [0, 1]
\]

越接近 1 越好。

---

# 58. 带容差的无关记忆稳定性

引入微小随机扰动容差 $\tau$：

\[
IMS_\tau = 1 - \frac{\max(0, |F - I| - \tau)}{1 - \tau} \in [0, 1]
\]

---

# 59. 无关消融结果的诊断内涵

若 $I > F$，表明系统存在严重的无关噪音干扰；若 $I < F$，表明时间线中被标注为无关的事件实际存在意外的隐式依赖。

---

# 60. 有害/陈旧记忆对照组设定

对比纯净对照组（$C$）与注入有害/过时信息组（$H$）的表现。

质询注入通道（`MIB-ADV-*`）是该条件的特例：有害注入仅包含预设了未确立值的**提问**，因此对照组 $C$ 与有害组 $H$ 的标准答案完全一致，$C - H$ 的性能差值即为「错误安装」的直接度量。该通道无需定义新指标——Memory Harm（§61）与 Harm Resistance（§62）完全适用。

---

# 61. 记忆损害量级（Memory Harm, MH）

\[
MH = E[\max(0, C - H)]
\]

以百分点（pp）列报，代表有害记忆引发的平均性能损失。

---

# 62. 抗有害记忆得分（HRS）

\[
HRS = 1 - \max(0, C - H) \in [0, 1]
\]

---

# 63. 记忆诱发错误率（MIER）

在纯净组完全正确的样本中，统计有害组发生错误的比例：

\[
MIER = \frac{\text{有害记忆诱发的可避免错误数}}{\text{合格的有害测试总轮数}} \in [0, 100\%]
\]

---

# 64. MIER 采用有效分母的原因

若纯净组本就做错了该题，则无法断定错误是由有害记忆诱发的，因此必须在合格对照基底上统计。

---

# 65. 净记忆增益（Net Memory Gain, NMG）

\[
NMG = MB - MH
\]

衡量记忆系统带来的正向收益与潜在损害之间的净差值（以百分点 pp 列报）。

---

# 66. 为什么 NMG 不等于 MIB Score

高绝对能力与低净增益、低绝对能力与高净增益代表完全不同的系统状态，MIB 坚持将二者独立列报。

---

# 67. 因果记忆效应维度得分公式

在维度层面将三大因果支柱加权合成为 0~100 的标准得分：

\[
CausalScore = 100 \cdot \frac{0.50 \cdot HMB + 0.20 \cdot IMS + 0.30 \cdot HRS}{\text{可用组件权重之和}}
\]

权重分配体现了三项核心准则：
- 相关记忆必须能够正向改善决策（50%）
- 无关记忆必须保持良性中立不产生干扰（20%）
- 有害或陈旧记忆必须得到有效免疫与抵御（30%）

---

# 68. 因果覆盖率透明度

报告中必须明确披露各项因果消融类型的实际覆盖率。

---

# 69. 模板级因果指标聚合

各项因果指标同样遵循“模板内实例先求均值，再进入维度加权”的严谨层级。

---

# 70. 严禁错误的池化计算

必须坚持在配对样本内部计算差值（$F_s - R_s$），严禁直接用不配对的全局均值相减。

---

# 71. 正向技能迁移增益（PTG）

在适用新情境下：

\[
PTG = F_{match} - R_{match}
\]

---

# 72. 负迁移量级（Negative Transfer, NT）

在不适用的情境下，因盲目套用技能导致的性能下降：

\[
NT = \max(0, B_{nonmatch} - F_{nonmatch})
\]

---

# 73. 抗负迁移得分（NTR）

\[
NTR = 1 - NT \in [0, 1]
\]

---

# 74. 负迁移发生率（Negative Transfer Rate）

\[
NTRate = \frac{\text{不当迁移发生次数}}{\text{不适用情境测试总机会数}} \in [0, 100\%]
\]

---

# 75. 失败教训规避能力

检验智能体在面临类似情境时是否会避开已知导致失败的路径。

---

# 76. 已知错误重现率（Error Recurrence Rate, ERR）

\[
ERR = \frac{\text{重复发生已知教训的失败次数}}{\text{面临相关情境的有效总机会数}} \in [0, 100\%]
\]

---

# 77. 错误规避得分（EAS）

\[
EAS = 1 - ERR \in [0, 1]
\]

---

# 78. 错误重现统计的有效机会准则

仅在智能体确实亲历过该失败教训、且当前环境确实提供该错误动作入口时计入分母。

---

# 79. 学习增益（Learning Gain, LG）

长程任务中后期表现与初期表现之差：

\[
LG = Performance_{late} - Performance_{early}
\]

---

# 80. 学习曲线下面积（AULC）

\[
AULC = \frac{1}{N} \sum_{t=1}^{N} Performance(t)
\]

同时奖励学习速度与最终能力水平。

---

# 81. 影响精度（Influence Precision）

\[
IP = \frac{\text{起到正向帮助的记忆影响数}}{\text{检测到的全部记忆影响数}}
\]

主要用于可选的深度诊断赛道。

---

# 82. 时序记忆计分细则

综合考核当前状态准确率、历史状态准确率、跃迁理解度与陈旧信息回避能力，杜绝用“仅返回最新值”伪装满分。

---

# 83. 认识状态记忆计分细则

综合考核信源归属（谁说了什么）、分歧保留、纠错识别与在未知状态下的审慎弃权。

---

# 84. 经验记忆计分细则

优先通过环境世界真实状态与动作轨迹来考核排障恢复能力。

---

# 85. 技能学习计分细则

必须同时包含正向迁移机会与非适用环境下的抗负迁移检验。

---

# 86. 选择性遗忘计分细则

同时考核对过时信息的抑制执行，以及在回溯历史时对过往档案的完整留存。

---

# 87. 前瞻记忆计分细则

考核基于环境情境的主动触发（自发涌现输出）、准时性与抗干扰持久度，杜绝被动提问作答。

---

# 88. 自我认知记忆计分细则

考核对自身局限的认知连续性与自我纠错，严禁记忆越权赋予环境操作权限。

---

# 89. 记忆幻觉的判定与扣分

智能体凭空捏造未曾经历过的过往事实属于记忆幻觉，由评测器标记并扣分。

---

# 90. 虚假置信度处罚

在客观真值为 `unknown` 的场景下妄加断言将判定为 0 分，主动弃权判定为满分。

---

# 91. 全上下文基准的作用

作为诊断对照，用于确立基座模型在完美信息下的能力上限。

---

# 92. 无记忆基准的作用

用于确立任务在完全没有历史记忆时的基础得分下界。

---

# 93. 记忆区分度指数（MDI）

\[
MDI = FC - NM
\]

$MDI$ 显著高于 0 是场景具备记忆评测价值的前提。

---

# 94. 淘汰无区分度场景

无记忆已接近满分、或全上下文也几乎得 0 分的场景，在校准阶段必须淘汰。

---

# 95. 记忆差距弥合率（MGC）

在赛道 A 中衡量记忆系统弥合了无记忆与全上下文之间差距的比例：

\[
MGC = \frac{F - NM}{FC - NM}
\]

---

# 96. MGC 的适用范围

仅适用于完全固定模型的赛道 A 诊断，不作为赛道 B 的通用指标。

---

# 97. 场景校准矩阵

场景在正式发布前必须通过四类基线（无记忆、全上下文、简单检索、高级记忆）的校准矩阵验证。

---

# 98. 统计层级不可混淆

重复运行、隐藏实例、场景模板与能力维度具有不同的统计含义，严禁混作等权样本。

---

# 99. 多轮运行标准聚合流程

```text
1. 评测器输出转换为探针得分
2. 配对绑定各因果实验条件
3. 实例内对重复运行求均值
4. 模板内对隐藏实例求均值
5. 维度内对各模板加权求和
6. 各维度得分加权计算 MIB Score
```

---

# 100. 均值作为主估计量

常规能力得分统一采用算术均值，响应延迟与成本等长尾指标增补中位数。

---

# 101. 方差与离散度呈现

报告中必须披露标准差、重复运行次数与隐藏实例数量。

---

# 102. 95% 置信区间要求

官方榜单主分数与主要因果指标必须附带 95% 置信区间。

---

# 103. 分层 Bootstrap 自助重采样法

标准推断方法：在各维度内对模板进行重采样，在选定模板内对隐藏实例进行重采样，同时严格绑定所有配对因果条件。

---

# 104. Bootstrap 重采样次数

官方榜单发布标准为 **10,000 次** 重采样。

---

# 105. 百分位置信区间计算

取 Bootstrap 分布的 2.5% 与 97.5% 分位数作为区间上下界。

---

# 106. 系统间配对显著性对比

对比两个系统在相同隐藏实例上的表现差异时，必须对实例级的配对差值（$Score_A - Score_B$）执行 Bootstrap，大幅提升统计功效。

---

# 107. 统计平手（Statistical Ties）的严谨表达

当两系统配对差值的 95% 置信区间包含 0 时，官方应当明确标注为“统计上无显著差异”，避免对微小分差进行过度解读。

---

# 108. 隐藏评测轮换与防刷榜

通过轮换种子与保留私有测试集，防止通过反复提交探查题库。

---

# 109. 统计置信度 vs 智能体认知置信度

严禁将评测框架的 95% 置信区间与智能体内部对某事实的信心程度混为一谈。

---

# 110. 维度最小样本准入

Profile 明确规定各维度至少需包含的规范模板数与覆盖率阈值。

---

# 111. 跨维度场景权重切分

综合场景对各维度的贡献权重必须显式切分（之和为 1），防止在所有维度被重复全额计入。

---

# 112. 避免因果效应的重复计分

因果消融带来的得分仅计入因果维度，不重复作为加分补贴到原能力维度。

---

# 113. 记忆容量不等于得分

存储量、向量数、图节点数不直接折算为能力分，仅计入系统效率指标。

---

# 114. 系统效率指标独立列报

包括 Token 消耗、读写开销、存储占用与延迟指标，严禁混入能力得分。

---

# 115. 帕累托前沿分析

倡导通过“得分-成本”、“收益-存储”等多维帕累托前沿呈现系统综合表现。

---

# 116. 容量压力与长时衰减

在 MIB-L 等压力测试中追踪性能随事件规模增长的衰减曲线。

---

# 117. 遗忘曲线诊断

区分正常时间衰减、语义覆盖与主动选择性遗忘。

---

# 118. 陈旧信息采纳率（SAR）

\[
SAR = \frac{\text{采纳陈旧答案的次数}}{\text{陈旧诱导总机会数}}
\]

---

# 119. 历史保真度（Historical Fidelity, HF）

\[
HF = \frac{\text{正确回忆历史状态的次数}}{\text{历史回溯探针总数}}
\]

优秀的系统应当同时实现“低陈旧采纳率”与“高历史保真度”。

---

# 120. 信源归属准确率（SAA）

\[
SAA = \frac{\text{正确归属信源的声明数}}{\text{信源考核总机会数}}
\]

---

# 121. 纠错保留双重考核

同时检验对最新纠错的采纳，以及对纠错前历史口误记录的准确回溯。

---

# 122. 证据独立性诊断

检验系统是否会将同一信源派生出的多个摘要误当作相互独立的交叉佐证。

---

# 123. 前瞻触发的准时性

基于虚拟时间评估前瞻自发提醒是在适当时机触发、滞后触发还是过早误触发。

---

# 124. 过早误触发惩罚

未满足条件即发生误提醒将予以扣分。

---

# 125. 自我局限认知连续性

考核智能体对自身已知局限的持续认知。

---

# 126. 权限混淆发生率（ACR）

统计记忆内容引发越权操作的发生概率。

---

# 127. 综合能力卡片（Capability Card）结构

完整卡片必须整合系统元数据、主得分及置信区间、八大维度得分与覆盖率、全套因果指标、执行成功率与资源效率。

---

# 129. 因果指标算例实操 —— 原始增益

```text
全量记忆表现：     F = 0.967
相关记忆消融表现： R = 0.300
无关记忆消融表现： I = 0.950
有害记忆注入表现： H = 0.700
纯净对照表现：     C = 0.967
```

原始记忆收益：

\[
MB = 0.967 - 0.300 = 0.667 \rightarrow +66.7\text{ pp}
\]

---

# 130. 因果指标算例实操 —— 空间归一化

剩余可提升空间：

\[
1 - R = 0.700
\]

净空间归一化收益：

\[
HMB = \frac{0.667}{0.700} = 0.953 \rightarrow 95.3
\]

---

# 131. 因果指标算例实操 —— 无关稳定性

\[
IMS = 1 - |0.967 - 0.950| = 0.983 \rightarrow 98.3
\]

---

# 132. 因果指标算例实操 —— 抗有害记忆

\[
MH = \max(0, 0.967 - 0.700) = 0.267
\]

\[
HRS = 1 - 0.267 = 0.733 \rightarrow 73.3
\]

---

# 133. 因果指标算例实操 —— 因果维度合成

\[
CausalScore = 100 \cdot (0.50 \cdot 0.953 + 0.20 \cdot 0.983 + 0.30 \cdot 0.733) \approx 89.3
\]

---

# 134. 综合主得分算例实操

加权计算得出：

\[
MIB_{base} = 77.21 \rightarrow 77.2
\]

---

# 135. 得分客观解读原则

77.2 代表在特定 Profile、赛道、规模和评测配置下的标准化得分，绝不能脱离上下文武断宣称“达到了人类水平”。

---

# 136. 得分发布必须包含完整身份标识

包含基准版本、Profile、Track、Scale、场景包版本、Agent 版本、模型版本与记忆系统版本。

---

# 137. 跨主版本得分不可比

主版本发生演进后，不同版本的得分严禁直接横向混排。

---

# 138. 场景修订与版本追溯

真值或计分逻辑发生调整时，必须递增场景版本并在评测报告中予以记录。

---

# 139. 评测器演进防漂移

LLM 裁判大模型升级时必须记录模型版本，防止评测标准发生静默漂移。

---

# 140. 统计过程全流程可复现

从场景包、种子列表、运行流水到最终计分公式，全链路保持可审计与独立验证能力。

---

# 141. 榜单准入门槛

包括通过适配器合规测试、满足必测覆盖率、故障率低于阈值以及提供完整运行记录。

---

# 142. 执行故障率指标（EFR）

\[
EFR = \frac{\text{执行失败探针次数}}{\text{计划执行探针总次数}}
\]

---

# 143. 不支持率指标（UR）

\[
UR = \frac{\text{未支持的必测场景权重}}{\text{要求的必测场景总权重}}
\]

---

# 144. 无效应排除准则

仅允许因基准基础设施故障（如模拟器崩溃）排除运行，参赛系统的认知错误或超时不得作为无效运行剔除。

---

# 145. 严禁事后针对性删题

发现题目缺陷必须通过版本化发布统一定点修复并对所有参赛系统重新重算，严禁针对特定系统事后挑题删题。

---

# 146. 缺失数据严禁隐式补全

缺失数据必须如实记录或按策略判定，严禁擅自填充有利分数。

---

# 147. 低频有害事件置信度展示

针对小概率事件必须同时展示发生次数、总样本量、发生率及其置信区间。

---

# 148. 比率型指标的分层 Bootstrap

各类比率指标统一采用分层重采样法计算置信区间。

---

# 149. 计分鲁棒性交叉核验

定期核验不同权重方案与聚合方式对榜单排名的敏感度。

---

# 150. 权重敏感度线性透明性

得分与权重之间保持清晰的线性加权关系，便于审计。

---

# 151. 严禁任何隐式加分项

未在规范中声明的开源加分、KIP 加分或架构加分一律严禁引入。

---

# 152. KIP 协议中立性

遵循 KIP 并不直接获得加分，唯有可观测的外在认知行为才是唯一的评分依据。

---

# 153. 模型能力与记忆能力的解耦

赛道 B 衡量端到端综合能力，赛道 A 专注于剥离基座模型后的记忆系统专项评测。

---

# 154. 基座模型能力天花板过滤

在全上下文（FC）下基座模型都无法完成的任务，必须在校准阶段剔除出赛道 A 评测包。

---

# 155. 基座模型能力下界过滤

在无记忆（NM）下即可轻松满分的任务，必须在校准阶段标记为无区分度。

---

# 156. 题目难度演进与版本隔离

随行业发展逐步增加长程与高对抗题目，各代际得分通过版本严格隔离。

---

# 157. 跨评测规模的留存度分析

\[
ScaleRetention = \frac{Score_L}{Score_S}
\]

---

# 158. 容量崩溃诊断

追踪系统在小规模（S）、中规模（M）到大规模（L）时的性能衰减轨迹。

---

# 159. 置信度分组呈现（Tiering）

将统计无显著差异的系统划入同一梯队呈现，避免误导性炒作微小分差。

---

# 160. 计分全流程可重算审计

通过命令 `mib verify-score report.json` 可以纯基于报告数据完整重现最终得分。

---

# 161. 运行期间严禁评测反馈

智能体在完成整个场景条件前，绝对不得接收到任何打分反馈。

---

# 162. 严禁跨条件记忆残留

全量组与消融组之间必须通过强隔离独立执行，严禁带入前序条件的记忆状态。

---

# 163. 执行次序随机化

各消融条件的执行次序可进行随机打乱，消除时序启动效应。

---

# 164. 因果重放干扰校验

严格保证消融特定事件不会意外改动其他无关事件的随机种子。

---

# 165. 消融有效性核验

确认目标事件在全量组中确实可见、在消融组中确实被移除、且非目标环境保持一致。

---

# 166. 多关键记忆消融策略

支持单点消融、组合消融或逐一剔除消融，并在场景中明确声明。

---

# 167. 协同记忆的组合消融

针对必须两段记忆共同起效的任务，采用组合消融作为语义单元。

---

# 168. 冗余记忆的信息集消融

对于包含冗余备份的信息，消融时应剔除整个关键信息集，而非单个冗余条目。

---

# 169. 证据冗余的信源语义消融

在认识状态场景中，剔除某个冗余信源可用于检验系统对置信度与佐证力变化的细微感知。

---

# 170. 权重治理公开透明

所有维度权重、模板权重、惩罚上限与因果公式均属于公开治理范畴，版本化发布。

# 173. 为何突出认识、经验与技能

MIB 强调深度记忆智能，因此给予证据溯源、经验轨迹与技能迁移更高的权重占比。

---

# 174. 为什么因果维度不占据 50% 以上权重

防止因果差值过大过度奖赏低基底系统，通过 12% 核心维度与独立因果度量实现兼顾。

---

# 175. 指标极值与定义域边界

能力维度界定于 0~100；因果差值指标完整保留正负号。

---

# 176. 异常结果自动告警

对 $MB < 0$、噪音消融后得分剧烈波动、无记忆得分超过全量得分等异常案例进行自动告警标注。

---

# 177. 超越全上下文表现的合理性

记忆系统通过压缩规律、形成技能与过滤噪音，完全有可能在表现上超越未经提炼的全量上下文。

---

# 178. 低于无记忆表现的判定

$F < N$ 说明记忆系统产生了反向误导，此时记忆收益判定为负值。

---

# 179. 报告呈现精度规范

主分数与百分点差值保留 1 位小数，底层机器报告保留完整浮点精度。

---

# 180. 机器报告 Schema 结构规范

后续通过 `mib-report.schema.json` 固化完整的机器可读报告字段。

---

# 181. 离线可重算性

报告包含完整中间统计量，无需重跑大模型即可完成全部指标的重新推导。

---

# 182. 原始输出的脱敏留存

在保护商业隐私与题库秘密的前提下，支持保存文本哈希与结构化判定流水。

---

# 183. 记忆智能是能力向量与标量的统一

标量分用于快速排名，八维能力向量与因果剖面用于深度技术分析。

---

# 184. 相同总分下的能力异构性

能力卡片清晰展现系统在记忆保留、时序演进与技能迁移等方面的技术异构特色。

---

# 185. 官方得分的严谨陈述句式

标准表述必须包含系统名称、得分、Profile、赛道、规模、场景包版本及 95% 置信区间。

# 186. 计分模型核心不变量汇总

1. **评测器输出严格归一化至 $[0,1]$。**
2. **能力维度得分采用全量记忆条件（Full Memory）下的表现。**
3. **因果记忆贡献与绝对能力水平独立分别列报。**
4. **MIB 综合得分不是单纯的有记忆减无记忆差值。**
5. **赛道 A 与赛道 B 严禁混合排名。**
6. **探针得分聚合优先于场景实例聚合。**
7. **重复运行聚合在场景实例内部进行。**
8. **隐藏实例在场景模板内先求均值，再进入能力维度加权。**
9. **实例数量绝对不能隐式改变模板的语义权重。**
10. **模板权重与维度权重属于版本化治理策略。**
11. **因果实验条件必须严格按随机种子配对执行。**
12. **原始因果效应指标（CMI / MB）完整保留正负符号。**
13. **归一化因果组件得分严格界定于 $[0,1]$。**
14. **相关记忆消融优先于无记忆对照。**
15. **消融后接近天花板的样本不纳入净空间归一化计算。**
16. **无关记忆稳定性同时惩罚意外的正向帮助与负向干扰。**
17. **记忆损害判定必须基于严格配对的纯净对照。**
18. **记忆损害量级（MH）与记忆诱发错误率（MIER）明确区分。**
19. **净记忆增益（NMG）采用同量纲百分点计算且不等于主得分。**
20. **负迁移必须独立可测。**
21. **错误重现率仅在经历过教训的有效情境下计算。**
22. **全上下文与无记忆对照属于标定与诊断基准。**
23. **无记忆区分度的场景严禁未经筛选进入正式包。**
24. **未满足必测覆盖率绝不能隐式虚高得分。**
25. **接口不支持与业务测试失败严格区分。**
26. **基础设施故障与业务认知错误严格区分。**
27. **客观环境真值判定效力高于大模型裁判主观意见。**
28. **全局防线扣分必须保持透明与版本化。**
29. **系统开销与效率指标独立于能力得分列报。**
30. **存储容量与数据规模不直接折算为 MIB 得分。**
31. **置信区间代表基准评测的不确定性，而非智能体的认知信心。**
32. **横向对比两系统优先采用配对 Bootstrap 显著性检验。**
33. **计分全过程具备离线可重算与可审计性。**
34. **私有思维链绝不作为强制计分项。**
35. **遵循 KIP 协议不获得隐式加分。**
36. **赛道 B 绝不私下进行大模型能力因子折算。**
37. **发布得分必须完整绑定 Profile 与环境配置身份。**
38. **多维能力卡片与单一综合标量得分同等重要。**

---

# 187. 最终准则

MIB 计分体系的设计，是为了在评测中同时确立三条铁律：

> **优秀的记忆系统必须在任务中表现出色；**

> **相关的过往记忆必须能够带来可量化的因果收益；**

> **无关、陈旧或有害的记忆绝不能支配未来的决策。**

基准追问的不仅是“智能体记住了吗？”，更是：

```text
记忆是否切实改善了正确的决策？
记忆是否准确维系了认知区分？
记忆是否坚决抵御了错误的诱导？
这一切能否在实验中稳定可复现？
```

这正是 MIB 综合得分与全套因果指标所衡量的事物。

# 附录 B —— 核心公式汇总表

## 探针 / 场景加权平均

\[
S = \frac{\sum_q w_q P_q}{\sum_q w_q}
\]

## 模板均值

\[
T = \text{mean}(S_{instances})
\]

## 维度得分

\[
D_d = 100 \cdot \frac{\sum_t v_{t,d} T_{t,d}}{\sum_t v_{t,d}}
\]

## MIB 基准得分

\[
MIB = \sum_d W_d D_d
\]

## 原始因果效应（CMI）

\[
CMI = F - R
\]

## 记忆收益（MB）

\[
MB = E[F - R]
\]

## 净空间归一化记忆收益（HMB）

\[
HMB = \frac{\max(0, F - R)}{1 - R}\quad (R < 1 - \epsilon)
\]

## 无关记忆稳定性（IMS）

\[
IMS = 1 - |F - I|
\]

## 记忆损害量级（MH）

\[
MH = E[\max(0, C - H)]
\]

## 净记忆增益（NMG）

\[
NMG = MB - MH
\]

## 已知错误重现率（ERR）

\[
ERR = \frac{\text{重复失败次数}}{\text{面临相关情境的有效机会数}}
\]

## 负迁移量级（NT）

\[
NT = \max(0, B_{nonmatch} - F_{nonmatch})
\]
