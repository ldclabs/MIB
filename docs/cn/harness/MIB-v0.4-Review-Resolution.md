# 2026-09-23 设计审查实施台账（第一轮）

> 度量版本 0.4.0 的历史台账。下文中的依赖门槛、先导预算以及若干程序构造已在度量版本 0.5.0 中修订；详见 [v0.5 台账](MIB-v0.5-Review-Resolution.md)。

实施版本 **0.13.0**，Core 度量版本 **0.4.0**，题库报告 **0.5.0**，内存后端报告 **0.2.0**。场景格式保持为 **0.2**。纵向度量/报告为 **0.2.0**；内嵌的原生工作流契约保持不变。

本台账落实了来自[审查报告](../../reviews/MIB-Design-Review-2026-09-23.md)的可执行缺陷。它将工程实现与实证验证严格区分开来。早期报告与示例 fixture 保留其原始版本/源标识；必须使用其匹配的可执行源码包进行核验，不得直接与本修订版本对比。

## 已落实项

| 审查项 | 变更内容 | 验证证据 |
|---|---|---|
| P0-01 标量判分 | 结构化回答默认采用精确规范化别名比较；生成的标量评分准则拒绝容器/非字符串，并以取值正确作为前置条件。泄漏检查仍扫描所有可见取值。 | 覆盖否定句、备选项罗列、全候选池枚举、JSON 容器、有效别名以及遗留披露测试。 |
| P0-02 依赖门槛 | 冻结每个声明的变更探针机会。联合成功率要求两个回答均正确；缺失/无效/错误的配对均保留在分母中。在实例内部对重复轮次取平均，聚类 bootstrap 按程序分层。 | 提高完整条件正确性不会抹除有效资格；重复轮次保持相同的独立 n 与置信区间；缺失孪生仍被计数；篡改报告将被拒绝。 |
| P0-03 准入资格 | 必要因果指标采用 pass/fail/unassessable。要求独立样本覆盖率与有效的完整/因果生命周期；校准设置记录在实验锁中。 | 空因果证据无法增加完整门槛计数；冒烟测试与先导实验绝不授予发布准入资格。 |
| P0-04 / P2-15 轮次标识 | 共享轮次具象化与完整阶梯校验。后端运行采用规范程序 ID；调度/锁标识每个实例与重复轮次。 | 14 个程序 × 3 个阶梯产生完整覆盖率与 14 条完整曲线。缺失阶梯与缺失冻结调度单元均被拒绝。 |
| P1-05 有界记忆 | 统一渲染器强制执行最终上下文字符上限（包括序号前缀与换行符）。超出限制的记录整条略去。 | 在 1/7/100/1000 字符预算下的超长与 Unicode 观测测试；外部后端上限保持强制执行。 |
| P1-06 公开交互历史 | 通过各记忆条件持久化已完成的公开问答交互与实际发射输出；B0 丢弃跨任务历史。 | 对话与发射在 B1–B3 中跨越边界保留，在 B0 中被清除；重复请求 ID 不产生重复记录；reset 清除前一次运行。 |
| P1-07 后缀捷径 | Core 获取与噪声交织穿插；维护发生在获取内部，跨阶梯不改变语义顺序或未来时间。 | 仅前缀 fixture 丧失能力分；完整参考保留正确性；跨阶梯不变量持续受测。 |
| P1-08 规程范围 | 将展示的 Core 技能标签收窄为规程记忆与适用性。增加包含未见项目族组合的独立特征复合挑战。 | 单纯项目族查表无法通过首试复合；真实特征反馈支撑完整/孪生成功。复合惯例由题目给出，因此并不构成不受限规则发现的论断。 |
| P1-09 纵向解读 | 保留安全的“先检查后行动”策略。将实际/检查工具调用及相比该策略的节省额，与安全性及原生结果分别独立报告。 | 所有三种需求状态在无记忆下依然安全可解；成本节省无法抵消不安全准备或失败提交。 |
| P1-10 带符号效应 | 增加带符号的有害历史效应与负迁移效应；单侧下行损失单独保留。分数差异在 JSON 中使用 `normalized_delta`，展示时转为百分点。纵向重复轮次在独立种子内聚类。 | 对称零均值波动对应零带符号效应，而截断损失保持为正；重复轮次不增加独立种子数。 |
| P1-11 基线对照 | 将 B3 标记为启发式显著性检索。Pilot 为 B1/B2/B3 和近期窗口诊断提供统一的上下文上限；oracle 支持的参考保持显式特权。 | Pilot 配置、预算渲染器、同模型调用审计与源码/配置锁。 |
| P1-14 承诺行为 | 增加独立的取消/续期/多重承诺/重复触发挑战。保留撤回与会话边界解读限制。 | 完整与孪生轨迹成功执行；扣留重新授权会使行为降级；重复触发严禁重复发射。 |
| P2-16 可选绑定 | 将 Brain 特定的记录 ID/分词器检查移入 `learning.bindings.brain`；选用的便携审计接收有界不透明 host ID 与带版本的分词器标识。 | 共享标识、工作流、预算与生命周期约束保持不变；Brain 参考检查依然拒绝非原生 ID。两种绑定均不证明原生学习。 |
| P2-17 / P2-18 操作工程 | 提供 smoke/pilot/full 配置；增加 `mib run` 配置分发、`mib compare` 与 `mib verify` 别名。增加 pytest 发现边界并同步版本元数据。 | CLI 预估/别名测试；锁定的 pilot 计划；常规 pytest 排除本地 debug 快照。 |

## 复现命令

```bash
python -m pytest -q
python tools/validate-review-20260923.py --output-dir /tmp/mib-review-0.4
python -m mib_runner run examples/same-model/same-model-generated.pilot.json --estimate-only
python -m mib_runner.same_model_cli examples/same-model/same-model-generated.stub.json \
  --output-json /tmp/mib-smoke-0.4.json \
  --report-schema schemas/mib-same-model-report.schema.json
```

本地最终验证：在 Python 3.14.7/macOS 上 **419 passed, 8 skipped**。跳过的测试需要 Linux 沙箱或评测方私有题库包。Core 与 Session 完整记忆 fixture 获得 100 分；仅前缀 Core fixture 获得 **67.348** 分且无法通过依赖门槛。独立的机制挑战在完整 fixture 下获得 100 分。42 单元工程 stub 具备 `fairness_valid: true` 与 `release_eligible: false`。这些属于工程结果，而非真实模型校准。

验证脚本将完整报告写入指定目录并输出精简的 `validation.json`；它不发起模型提供方调用，亦不需要私有题库包。已提交的 `examples/validation/measurement-0.4.0.json` 是精简的工程记录，而非模型表现证据。stub 运行同样仅属于执行与报告检查。

有界先导实验当前预估执行 **463 次条件运行**和**至少 1,826 次业务模型调用**，排除所有后续轮次、工具结果决策、重试、预检和额外诊断调用。它在单个阶梯档位覆盖 7 种机制，与完整校准属于不同实验。观测路由采用公开的 `environment_event` 类型，等权应用于所有记忆臂；所有常规观测依然进入记忆形成。隐藏探针/相关性标签绝不用于筛选模型调用。

## 剩余实证与部署工作

- **P1-12：** 真实固定模型先导实验、统计功效/样本量规划、多模型复现、预先登记的有效效应量阈值以及官方冻结，需要配置不可变模型标识/端点并执行服务商调用。此处不声称已进行此类运行。
- **P1-13：** 新挑战提供了额外机制，但独立编写/保留的措辞、双盲语义 oracle 审查与独立的真实领域依然是必需的。公开随机种子或新参数值无法提供这些保证。
- **P1-14：** 固定包装器与本地契约已经过测试；任意远程进程重启、存储存续、跨租户隔离与物理删除仍需要具体的部署证据。撤回合规性不等于删除证明。
- **P1-10：** 相关历史移除估计的是扣留这些事件的总体效应。进一步识别内容与长度/决策机会差异需要切合领域的匹配替换。危害安慰剂不是通用的替代品。
- **P2-15/17：** 统一的标识/具象化/评分接缝已实现。评测服务、遗留静态测试框架与实验赛道依然独立调度；这些修复既不需要也不声称对执行器进行完全重写。详细的遗留诊断依然可用。进一步移除或整合应由实证证据决定。

小样本 bootstrap 策略依然属于开发性质。简并区间记录的是观测到的经验分布，而非对未见任务的确定性。此处未调整任何阈值来制造真实模型的通过。
